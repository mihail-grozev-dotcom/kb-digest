Title: Sending an Email
You can use the Logic Library to send out a single email from your survey. This can be done using either the "Send An Email" element in the Survey Editor or the "email" logic node in the survey XML, and because it is only run once, can be a great way to follow up with congratulatory offers or other messaging for participants completing a live survey.
1: Using the Survey Editor
To add email sending using the Survey Editor, click + Add Survey Element under the staging area.
In the Element Library, select Advanced and select the Send An Email element. Then click Add.
The new element will appear in the staging area, where you can specify who to send the email to and when.
The following options are configurable:
RECIPIENT:
Recipient: Who will receive the email. Enter the email address for the intended recipient.
Subject: The messaging to appear in the subject line of the email sent to the recipient.
Body: HTML content of the email sent to the recipient. Click into the text-box to view the text toolbar and enter content.
SENDER:
Sender: The name of the email sender (for example, your name or company name).
Sender Email: The email address belonging to the email sender. Using a different sender email address can improve your email’s deliverability rates.
Note: Sender addresses must use a SendGrid enabled domain only; contact Technical Support for assistance.
Company Information: The company name and physical address to be shown in the email footer. This information is required for emails to comply with CAN-SPAM regulations.
Reply-To: The email address recipients should reply-to with queries or issues.
Schedule Send: The number of seconds to wait before sending the email to a participant who has completed the survey. The maximum wait time is 3 days (259,200 seconds). Click into the text-box to enter a number or hover over it to display and use the single-digit increase arrows.
CALENDAR INVITE (OPTIONAL):
Summary: The name for the event as it will appear in recipient's emails and calendars, if accepted (for example, "Employee Appreciation Party").
Description: The description of the event as it will appear in recipient's emails and calendars, if accepted.
Location: The location for the event described in the calendar invite (for example, "740 Evergreen Terrace, Springfield").
Start Date: The event start time (for example, 2017-10-31 11:30:00 or 11:30AM 2017-10-31).
End Date: The event end time (for example, 2017-10-31 12:30:00 or 12:30PM 2017-10-31).
Timezone: The event timezone (for example, US/Pacific or US/Eastern).
2: Using the XML
To send out an automated email, you will need to add a <logic> tag to your survey XML, specifying both a label and uses="email.1":
<logic label="email" uses="email.1" />
2.1: Parameters
The following parameters can be passed to the email logic node:node:
Attribute
Description
email:senderEmail
The email address belonging to the email sender.
Note: Sender addresses must use a SendGrid enabled domain only; contact Technical Support for assistance.
email:recipient
The recipient's email address.
email:subject
The subject of the email.
email:content
The HTML content of the email.
email:company
The name of the company shown in the email footer as its sender (you should also include physical address for CAN-SPAM compliance).
email:sender
The name shown in the "From" field on the email (the sender address will always be nobody@decipherinc.com)
email:reply
The name shown in the "Reply-To" field on the email.
email:delay
Sets a delay on sending the email (in seconds); the email is not sent out until the specified amount of time has passed.
Note: Any remove list, etc., using bulk is ignored due to the computer resources required. See Email Sends with Bulk for more information about bulk emails sends.
2.2: Example
<text label="q0" title="What is your email?" verify="email"/>
<res label="content">
<h3>Congratulations on completing the survey!</h3>
Great work clicking on all those:
<ul>
<li>Radio Buttons</li>
<li>Checkboxes</li>
<li>Submit buttons</li>
</ul>
&lt;hr/&gt;
This email was sent from <physical mailing address here>.
</res>
<suspend/>
<logic label="email"
email:recipient="${q0.val}"
email:subject="Confirmation on completing the survey"
email:content="${res.content}"
uses="email.1"/>
<text
label="q1">
<title>q1</title>
</text>
2.3: Additional Considerations
2.3.1: Customizing the Email
The email sent by the email logic node is blank by default and requires manual input of all text and styling. You can use HTML and CSS to customize your email, but keep in mind that all emails should comply with CAN-SPAM laws and best practices.
The email logic node will now include an optout link upon sending of the email logic node. The opt-out link will automatically adjust based on whether the email logic node is branded or unbranded.
Branded email logic nodes will not have any reference of Forsta (Decipher, FocusVision) in the following fields below:
Note: The opt-out link will adjust to the company remove list upon sending an email.
Subject
Body
Sender
Company Information
Reply-To:
Summary
Description
Unbranded email logic nodes have references to Forsta (Decipher, FocusVision) in the listed fields above. All unbranded opt-out links will automatically be adjusted to Forsta opt-out link.
2.3.2: Including a Calendar Invite
You can include an optional calendar invite with any email by adding the following attributes:
Attribute
Description
email:calendar_summary
A brief summary of the calendar invite ("Employee appreciation party").
email:calendar_description
A detailed description of the calendar invite.
email:calendar_start
The start time for the calendar invite. Must be in one of the following formats:
YYYY-MM-DD HH:MM:SS
HH:MM:AM/PM YYYY-MM-DD
For example, to start the invite at 11:30am on October 31, 2017, you would enter 2017-10-31 11:30:00 or 11:30AM 2017-10-31.
email:calendar_end
The end time for the calendar invite. Must be in one of the following formats:
YYYY-MM-DD HH:MM:SS
HH:MM:AM/PM YYYY-MM-DD
For example, to end the invite at 12:30pm on October 31, 2017, you would enter 2017-10-31 12:30:00 or 12:30PM 2017-10-31.
email:calendar_timezone
Calendar invite timezone (e.g., "US/Pacific" or "US/Eastern", etc.). See below for a list of available timezones.
email:calendar_location
Provide a location for the calendar invite ("740 Evergreen Terrace, Springfield").
