Title: 153.40 Release Notes
Release Date: September 10, 2024
Release Version: 153.40
New Features
Survey
Dynamic Questions
System translations for Video Testimonial's "Record or upload an existing video" and "No file chosen" in participant view have been updated for survey languages "Chinese (Traditional)" and "Chinese (Simplified)", to match Ziggeo's translations.
Architecture and DevTools
Data Retention
Data retention for both temp-view directories and the data generated by asynchronous API calls has been reduced to 2 days from 21 and 7 days, respectively.
Bug Fixes
Survey
Dynamic Questions
Some display-related functionality issues in the current version 3 of video player have been resolved:
In desktop environments, double-clicking the video when "Allow fullscreen" is unchecked no longer enables fullscreen mode.
When "Hide Poster on Pause/Finish" is checked, the video will display only a black screen before starting playback, and after finishing playback.
In desktop environments, when watermark text is applied, it will remain visible even when the video is paused.
Integration
An issue preventing some unicode characters from being used in Kinesis Panel registration passwords has been resolved.
Responses
Participant Sources
An issue that caused Sample Marketplace sources to be incorrectly categorized as Sample Provider sources, has been resolved.
