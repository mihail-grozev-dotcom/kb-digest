Title: 154.14 Release Notes 
Release Date: February 10, 2026
Release Version: 154.14
New Features
Portal
The retirement notification email now emphasizes the urgency to migrate soon-to-be-retired surveys.
Reporting
Data Downloads
Data Downloads now includes the JSON with Labels and Tab Delimited (Unquoted) formats.
Programming and Tools
API
A new endpoint allows reading and writing of user permissions per survey.
Learn More: Survey Users
Surveys
Project Hibernation is now live. Inactive projects are automatically moved to slower-access storage and reactivated when accessed.
Learn More: Hibernation Surveys
Bug Fixes
Portal
An issue preventing users in one regional company from being added to user groups in a different company within that same region has been resolved.
Survey
Dynamic Questions
Video Player (YouTube/Vimeo) now features improved support for the source platform's native controls. This applies to version 4 and 5.
Learn More: Video Player (YouTube / Vimeo) Element
XML Editor
Attempting to remove the <samplesources> tag from survey XML will now result in an error message, and changes will not be saved.
Programming and Tools
The mailimp script now runs successfully in the latest production environment.
Custom Code Elements (Logic Nodes)
The Research Defender REVIEW v1 logic node no longer automatically terminates any respondent record generated by SST.
