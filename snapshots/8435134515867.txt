Title: Managing Group Shuffling and Conditions
1: Introduction to Shuffling & Groups
When displaying a question, you will tell the system that rows will be shuffled (shuffle="rows"). The shuffle order will come from another question using shuffleBy , set by running q.rows.shuffle.order = ... or will come from a random order.
If the rows belong to groups, then after shuffling from any source, the rows will be reordered to fit the original group order unless shuffle="rows,groups" is set – then that group order is also shuffled.
It is important to note that only rows and not groups have an order. Groups are merely headings that appear before a row if the groups are different than the previous row. Thus if rows r1,r2 and r3 belong to groups g1,g2 and g2 respectively, we will display the heading for g1 before r1, then heading for g2 before r2. As r3 belongs to the same group as r2, no extra heading is displayed.
A row can belong to any amount of groups (e.g. <row groups="g1a,g1">). The first group mentioned is the “primary” group, and the others are secondary. By default, the primary group is only displayed when displaying a list of rows. The other groups appear if you set groupDepth="2" or higher. This requires you to have a hierarchical group or the resulting display will be confusing.
Note: Groups can be applied on rows, columns or choices; just “rows” is used as an example below.

4. Cond= attribute on <group>

The condition is the same syntax as you can put on a row: The group variable is set to the current group, just like row is set when running rowCond.

Rows can belong to multiple groups and if the group's conditions become false, it stops the row from being displayed. For example, if some rows belong to group "g1a" and group "g1" containing g1a, then a condition like group.label == "g1a" will not display anything, because it will be False for the containing "g1" group. You can work around this by setting an explicit cond="1" on the parent groups.
6: Shuffle="rows,only_groups" to shuffle just the groups
When shuffling an item, you can specify: shuffle="rows" to randomize the rows, but keep the group order intact. You can set shuffle="rows,groups" to shuffle the rows within the groups, and also randomize the group order (of the primary groups only).
The shuffle="rows,only_groups" option means the groups only are shuffled, but the rows are not shuffled.
You can use this with shuffleBy="source" and shuffle this question’s groups by the corresponding groups in the source question. When shuffle contains only_groups the rows within groups are not shuffled. Source would be the question they are wanting to mimic randomization from, and they have to have the same number of groups and rows.
Example:
<checkbox label="q2" atleast="1" groupDepth="2" groupCond="q1[group].any" shuffle="rows,only_groups" shuffleBy="q1">

9. Working with nested groups
If you have nested groups, you can use q3.rows.groups.parents to go one level up in the group list (this can also be repeated multiple times). If your rows belong to g1a which in turn belongs to g1, the normal .groups will return g1a while applying .parents to it will return g1.

10. Copying Group Shuffle Order Between Questions
Assign a value to q3.rows.groups.order to change the row order to match these groups.
The value can be one of these:
A list of groups from another question
A list of strings that are group labels
For any group or label given that matches a group in the question, those rows will be shown first. Any remaining rows will be inserted at the end, without changing their original order. Groups given that do not exist in q3b will be ignored and will not generate an error.
Note: The target question (q3) must have shuffle set to "rows,nogroups". The "rows" must be enabled if you are changing row order. The "nogroups" option is required to avoid groups being reordered back to standard positions after shuffling.
Examples:
<# get the list of groups inside q2 and find the current order for this respondent# then reorder groups and their rows in q3 to match
q3.rows.groups.order = q2.rows.groups.order
# shuffle groups in q3 in this label order. The rows themselves remain in XML order
q3.rows.groups.order = ["g2c", "g2b", "g1a", "g2a"]
q3.rows.groups.order = q2.rows.groups.order
# shuffle groups in q3 in this label order. The rows themselves remain in XML order
q3.rows.groups.order = ["g2c", "g2b", "g1a", "g2a"]
11. Copying shuffle order of the parent groups
Assuming your rows are contained within groups g1a which in turn are contained within g1: you want to copy the group order of g1 before g2, but not shuffle any groups within that.
Use:
q2.rows.groups.order = q1.rows.groups.parents.order
A manual alternative:
q2.rows.groups.order = ["g2", "g1"]
q2 must have the attributes shuffle="rows,only_groups" set.
12. VectorPlus additions
You may be familiar with asking for q1.any to see if any item in q1 has been answered, or q2.r1.all to see whether all columns of row r1 have been checked.
This release extends this to support groups and also adds a more flexible way to deal with multiple data points at a time. You can copy answers between questions, find common answers, add data cells and many others all by accessing a special .vals object.
You can think of it as the named ranges in Excel: there you can say =SUM(R1:R5) to sum up just a small part of the spreadsheet; here you can say q1.g1.vals.sum() to get the sum of the subset of the q1 data which is contained within the g1 group.
Here are some examples of what you can do to a group element:
<# Start with q1, narrow data to only that in g1, then assign 5 to every cell
q1.g1.vals.val = 5
# Specify a row or column -- assign to only c1 vals here and not the other columns
q1.g1.vals('c1').val = 5
# for every checkbox answered in q1's g1 group, set a corresponding checkbox in q2
q2[q1.g1.vals] = True

14: Filtering by Answers to another Question
You may be familiar with this syntax:
for row in q2.rows:
if q1[row]:
row.val = 1
This goes over the rows in q2, then find the corresponding row in q1 – matching them up by label – and checks whether it was selected. If so, the value of the row in q2 is set to 1.
The .vals simplifies this: first, q2[q1.vals] will start by finding all the values in q1. Indexing q2 by that will generate corresponding q2 values, but only where the q1 values were true. The q2 values are selected by matching columns and labels exactly. Extra cells are ignored.
Afterwards, you can assign to it: q2[q1.vals].val = 1 – this changes every value in q2, where the corresponding cell in q1 was true – no matter how many matching values there are.
15: Filtering with Conditions
The vals object can be filtered by specific answers or conditions.
Examples:
If q3.vals > 50: – take every value in q3 and then compare each of it to 50. This results in a vals list with only. You can put the result inside an if check to see if at least one cell was above 50, but you can also use this to filter another question: q1[q3.vals > 50].val = 0 will set to 0 every cell in q1, where the corresponding cell was greater than 50.
You can filter the question by itself as well: q1[q1.vals > 100].val = 100 will change any cell that is above 100 to 100.

16: Combining Data from Multiple Questions
Rather than comparing each value in vals with a specific value, you can compare data in two questions to each other. The comparison will be true for the cell that exists in both questions (i.e. both questions must have at least one element with the same combination of row and column label) and matches the condition.
For example:
Example
Description
if q1.vals == q2.vals:
Is there at least one cell that was answered with the same value in both q1 and q2?
if len(q1.vals > q2.vals) > 5
Are there at least 5 cells, answered in both q1 and q2, that were larger in q1?
if q1.vals & q2.vals
Are there answered cells that were both in q1 and q2?
q1.vals | q2.vals
Find the answered cells answered EITHER in q1 or q2 (this is an exception to the matching requirement).
Like before, the output of this can be used to modify cells.
For example:
q3[q1.vals | q2.vals].val = 1 – set every q3 cell that was answered in q1 OR q2 to 1.
The questions compared do not have to match in any way – but only the row/column labels that do match are compared.
Note: Cells without answers are not included in the comparison. So “q1.vals != q2.vals” will not consider unequal a cell that was answered in q1 but not in q2
17: Merging Data from Multiple Questions
If you have multiple numeric questions, you can add them up cell by cell. The result is another .vals object which can then be assigned to a question or compared:
if (q1.vals + q2.vals) > 10:
This adds up every cell in q1 with the corresponding one in q2 (unanswered cells count as 0). Then every combined cell is checked to see whether it is greater than 10: the if the check succeeds if at least one such added cell is greater than 10.
You can also subtract or multiply values if needed. The computed data can also be assigned to another question:
q4.vals = q1.vals + q2.vals
q4[(q1.vals + q2.vals) > 10].val = 1
The first example adds up q1 and q2 and puts the results into corresponding cells in q4. The second example adds up q1 and q2, finds every cell larger than 10 and sets the corresponding cell in q4 to 1.
17.1: Writing to the values
If you have q1.g1.vals you can also write to every cell in that the group consists of by writing q1.g1.vals.val = 42.
This applies to any .vals object you might get hold of – whether it’s every cell in a question or only a subset. You do not have to have just a single number on the right hand side: it can also be another question’s vals: q1.vals = q2.vals will copy all data from q2 that matches cells on q1 side.
Both the sides can be combined with all the filtering features we’ve seen above:
q1[(q2.vals < 10) & (q1.vals > 10)].val = q2.vals + q4.vals
This finds all the answer in q2 lesser than 10, matches it with corresponding cells in q1 that are greater than 10 and copies that data from q2 added to q4. So if r1 in q2 was less than 10, and the corresponding r1 in q1 was greater than 10, it will receive the value from q2.

20: Change the order of groups in q2 to match q1, but let q2 have its own row order within those groups
q1 must have shuffle="rows,groups". This will shuffle the rows, but also allow groups to be shuffled – rather than groups returned to their XML order.
q2 must have shuffleBy="q1" shuffle="rows,only_groups". The only_groups will make only the group order, but not the row order within the groups be copied. Without only_groups, the group order in q2 would be returned to the original XML order when done.
The rows and q1 and q2 can be different in number and labels. There must be at least one common group label between q1 and q2 or the survey will not load.
Get a list of labels for some items:
List of labels for the rows in q1: q1.rows.labels – this returns e.g. ['r1', 'r2', 'r3', 'r4', 'r5', 'r6', 'r7'] in the order they are defined in the XML.
List of labels for the q1 rows in the order displayed to the respondent (after shuffling): q1.rows.order.labels –
Note: This does not take into account conditions or MLS.
21: Sudoku Validation Example
Consider an example question q1, which has 9 rows and 9 columns that will be filled with sudoku numbers. To validate a sudoku you must ensure that not only does each row and column have 9 unique values, you must also look at 9 9-element squares that make up the sudoku grid.
Assuming that the rows r1..r9 are arranged into groups y1 through y3, and same for the columns arranged in groups x1 through x3 this will be simple using this code:
<for x in q1.rows + q1.cols:
print "%s = %d unique values" % (x.label, len(set(x.vals.dataValues)))
for x in q1.cols.groups:
for y in q1.rows.groups:
print "%s+%s has %d unique value" % (x.label,y.label,
len(set(x.vals(y).dataValues)))
We look at both rows and columns and use the new cell.vals.dataValues to return a list of selected values. Using set() on it removes unique numbers, and len() counts them.
Review each group attached to columns, then each attached to rows. Using the group.vals(other_group) syntax we take all the values that belong to the group and narrow them down by values belong to the other group. We can then again call .dataValues to return the 9 values in the combination.
