Title: Options for Verifying Response Formats
The "Verify" option must be used in Text elements to ensure their proper functionality. The options in the "Verify" menu allow you to restrict a response to a certain format (e.g., an email address or phone number).
Note: "Verify" options can be set for a question or for one or more of its specific response options, but not for both.
1: Adding Verification
First, add a Text question. The verification options are available in the general options for the element, affecting the entire element.
You can also verify the response for a specific row or column within the Text question. To do this, click the row or column to access the options, then select the desired verification format option from the "Verify" drop-down menu.
1.1: Digits
Verifies that the response is a whole, positive number (e.g., 1, 123, 9999).
1.2: Email Address
Verifies that the response resembles an email address. The response should contain the @ symbol, followed by a period (.) and ending with two to four characters (e.g., user@domain.com).
1.3: Number
Verifies that the response is a whole number, integer, or decimal (e.g., 100, 10.0, $10, 10.00, 1,000).
1.4: Phone Number (US)
Verifies that the response is a 10-digit U.S. phone number (e.g., 559123456).
1.5: Zip Code (U.S.)
Verifies that the response is five digits long.
1.6: Extended Zip Code
Verifies that the response is five digits long, immediately followed with a hyphen, and includes four more digits (e.g., 93722-1234).
