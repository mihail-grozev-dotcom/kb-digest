Title: This or That Element
1: About the This or That Element
The This or That element allows you to set labels for contradictory concepts on both the left and right side of a response grid, creating a question where participants can rate their preference for either concept in a single row.
By default, each row legend in a This or That element is randomized once per participant. Additionally, a hidden question is automatically added to the report to track the participant's normalized (de-rotated) responses.
2: Adding a This or That Element
To add a This or That element, first click the "+ Element" button to add a new survey element. Then click "Single and Multi Select" under Question Types and select the "This or That" element. Then click "Add".
Enter the question and instruction text in the areas provided.
2.1: Adding Rows
Click "+ New Row" to add each new row, then enter the text for two opposing concepts into the boxes under the legend headers.
By default, the text in the box under "Left Legend" appears on the left side of the response grid, while the text in the "Right Legend" box appears on the right side of the response grid.
Note: Add as many rows as you like, but make sure that each row contains only its two opposing concepts (e.g., "enthusiastic" / "indifferent").
2.2: Adding Columns
Together, the columns define the difference scale for the This or That element. Click "Add Columns" and add one column with the text for every notch you would like to appear between the opposing concepts.
Add as many columns as you like, making sure to include some text for the column header. To add a column, click "+ New Column".
2.3: Additional Considerations
When adding a This or That element, the following limitations and considerations apply:
Columns should not be randomized. As row legends are automatically randomized in This or That elements, randomizing columns can result in reporting errors.
The This or That element renders responsively on mobile devices and will not look like its desktop version. Use short column texts and horizontal mobile displays for best results.
3: Viewing the Report
Because the column legends in a “This or “That” element swap per row, the data for each "This or That" element is split into two tables in the report. The first table displays the standard breakout for each concept, while the second table is a "normalized" version of the question, which displays the relative position of each concept.
3.1: Table 1 (standard breakout)
Similar to other Crosstabs tables, the first table includes the total counts for each concept. In this case, each count represents the number of times each column was selected for each row.
3.2: Table 2 (relative position)
The second, "normalized" table is generated by a hidden question that de-rotates the concepts within the rows and calculates the difference between each concept and the selected option. Essentially, the numbers shown here indicate how close each option is to the legend that was selected.
3.2.1: Concept Labels
In the second table, the de-rotated concepts are labeled according to their location in the grid. Concepts shown to the left of the grid appear as "rxx_l", while concepts shown to the right appear as "rxx_r".
