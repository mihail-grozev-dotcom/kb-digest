Title: 153.3 Release Notes
Release Date: March 14, 2023
Release Version: 153.3
New Features
Survey
Participant View
Most screen-readers now read the "please select an answer" error for each radio/checkbox in a grid question.
Programming and Tools
Custom Code Elements (Logic Nodes)
Upgraded the Imperium QualityScore logic node (qualityscore.2) to use the latest version (v1.4).
Learn More: Imperium QualityScore Integration
Architecture and DevTools
Errors that happen when sending email via Campaign Manager are now logged with better debugging information in the exceptions directory and in bulk.out.
Bug Fixes
Survey
All native survey templates with dynamic questions have been updated to use the most recent versions of those questions.
Canceling a launch or relaunch midway no longer results in a fatal error.
Language Manager
The Language Manager import now supports all unicode characters, including emojis.
Responses
Campaign Manager
Email sends no longer error when the subject line includes a variable and the replacement value from the list is particularly long.
Reporting
Crosstabs
Table sets within the Crosstabs report settings can now be created and saved.
Pressing the save button multiple times when saving a crosstab no longer saves duplicate crosstabs.
Programming and Tools
The Excel 97 (XLS) files generated by xlate now support all unicode characters, including emojis.
Architecture and DevTools
The background task that updates bouceback information no longer fails with a duplicate key error.
Temporary files created during document and image conversion are now cleaned from the servers once the conversion process is no longer using them. Files will no longer be accumulated, thus saving server resources.
