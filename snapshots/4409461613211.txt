Title: Configuring Crosstab Settings
Crosstab settings are accessible when you first build a new crosstab report, immediately after you have run a crosstab report, and when you are viewing saved crosstab reports.
1: Accessing Settings
There are three ways to access the Crosstabs Settings page.
1.1: For New Crosstabs
To configure the settings for a new crosstab, click the Settings button at the top left of the new crosstab menu.
1.2: For Saved Crosstabs
To edit the settings for a saved crosstab, click the gears icon for the desired crosstab on the Crosstabs Entry Page.
1.3: For Applied Crosstabs
To edit the settings for a crosstab you have already run (a crosstab that you currently are viewing), click Edit Settings at the top right of the crosstab report.
2: Overview of the Settings Menu
Listed below are the configurable settings available for each crosstab report.
1. Name & Description: Enter a name and description for the crosstab.
2. Filters: Create filters for the crosstab using dates and report segments.
Date Range: Filter results by a date range.
All: No date filter/show all.
Custom: Enter a custom date range in the From/To fields.
Calendar: Filter by the following options, based on the current date:
This Week
This Month
This Quarter
Previous Week
Previous Month
Previous Quarter
Day: Filter by day, based on the current date:
Today
Yesterday
Previous 7 Days
Previous 30 Days
Previous 90 Days
From / To: If a date range is selected. these fields reflect the range selected, based on the current date. You may also enter a custom date range.
Additional Filter: Allows you to restrict the participants to only those who fall into the selected segment. A list of saved crosstab segments is displayed in the menu. Crosstabs can only be filtered one segment at a time.
The options in the list are automatically created from saved segments. If the desired segment is not available, create that segment as a crosstab first. Once saved, segments in the crosstab are available to use as filters.
3. Content: Designate the participant type and table set configuration for the crosstab.
Participant Status: Allows you to select participants based on their survey completion status.
All and Partials: includes all participants, regardless of partial or completion status. Only available when automatic partial recovery is enabled.
All Complete Participants: includes all participants who have completed the survey (as qualified, terminated, or overquota).
Qualified Only: includes only participants who have completed the survey as qualified (not terminated or overquota).
Terminated Only: includes only participants who have completed the survey as terminates.
Overquota Only: includes only participants who have completed the survey as overquotas.
Partials Only: includes only participants who have not completed the survey. Only available when automatic partial recovery is enabled.
Table Set: Allows you to select which "table set" to apply to the crosstab run. A table set is a subset of tables that you define; for example, demographics. Any table set you save is available as an option in the "Table Set" menu.
New Table Set: Create a new table set.
4. Basing: Designate the report base and weighting scheme for the crosstab (if applicable).
% Base: Allows you to calculate percentages based on participants' question/segment status
.
Total Answering: Based on the "total" row, the total for the table row is updated for a participant if at least one visible row is true (excluding aggregated and nets).
Total Shown: Based on the number of participants shown any part of the question.
Total in Segment: Any participant who falls into the segment's condition (for example: qualified and male).
Total Shown Variable: Based on the number of participants shown a specific variable.
Weighting: This drop-down is only available if you have uploaded a weighting scheme for the crosstabs. It allows you to select a weighting scheme to apply to the crosstabs.
5. Crosstab Preview: View a preview of the crosstab segments with the applied stat-testing groups.
6. Stat Testing: Designate the test group and test levels used for performing statistical significance testing in the crosstab.
Stat Test Groups: Use commas to separate segments into stat test groups. Each segment is represented by the letter shown in the Crosstab Preview.
For example, A-C, DE, F or ABC,DE,F would stat test segments A vs. B vs. C together. It would also test D vs. E separately, and F would not be stat tested against any other segments.
Stat Test Levels: Set the thresholds for indicating statistical significance.
Stat Test Type: Select the type of calculation for Statistical Testing.
Learn more: Statistical Testing in Crosstabs
Tip: Click the undo icon to revert the stat testing groups and levels back to the default.
7. Permissions: Designate which users can view and edit the crosstab.
Private: Only you (the owner) can use/edit this crosstab.
Editable: Any logged-in user can edit this crosstab.
View Only: Any logged-in user can view this crosstab. Only the owner can edit or delete.
See Crosstabs Technical Considerations for more information about permissions.
