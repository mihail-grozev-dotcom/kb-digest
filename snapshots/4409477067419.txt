Title: Card Sort Single Select Element
The Card Sort Single Select element utilizes a single select form and must contain cards (rows) and buckets (columns). This element is mobile compatible and does not use Flash.
Tip: See Customizing the Card Sort Element to learn how to customize the Card Sort Single Select element using the XML Editor.
1: Adding a Card Sort Single Select Element
Note: You can set the "Show if" filter to display only elements that are compatible or optimized for the devices allowed for your project. See Project Settings Summary to learn how to verify your project settings.
To add a Card Sort Single Select element, first click the + Element button to add a new survey element. Then click Rate, Rank, and Sort under Question Types and select the Card Sort Single Select element. Then click Add.
Enter the question and instruction text in the areas provided.
1.1: Adding Cards
Click "+ New Card" to add each new card, then enter the text for the response option in the text field.
1.2: Adding Buckets
Click + New Bucket to add each new bucket, then enter the text for the response option in the text field.

3: Style Settings
To configure the style settings for a Card Sort Single Select element, click the ellipsis (...) button at the top right of the element in the staging area and select Update Styling.
In the Question Display Options modal, use the options on the left to specify how the question displays to participants. When you mouse-over an option, information about the feature displays on the right.
All of the texts listed below can be shown in each participant's respective language. See Language Manager Overview to learn how to manage translations for your survey.
Auto Advance Cards: When checked, cards will automatically advance to the next card after being answered.
Note: This option only applies to the Card Sort Single Select Element.
Auto Submit: When the last card is checked, the page is submitted.
Allow Drag And Drop: When checked, drag and drop is allowed on cards. When unchecked, cards can only be added to buckets by using the mouse.
Animation Duration: Allows you to change the animation duration of the cards in milliseconds. 0 is no animation, 500 is half a second, and 1000 is 1 second.
Display Navigation: When checked, the "previous" and "next" buttons are shown. When unchecked, the "previous" and "next" buttons are not shown.
Note: For card sort single select questions, when auto advance cards is unchecked, the "next" button will always be shown to allow advancement.
Note: For card sort multi-select questions, the "next" button will always be shown to allow advancement.
Previous Button Text: Allows you to enter text/HTML for the "previous" button.
Next Button Text: Allows you to enter text/HTML for the "next" button.
Display Card Progress Counter: When checked, a card counter is shown to indicate progress. When unchecked, the card counter is not shown.
Display Bucket Counter: When checked, a counter will be displayed on each bucket indicating how many cards are in that bucket. When unchecked, the counter will not be displayed.
Completion Message Text: Allows you to enter text/HTML for the completion message. This text is displayed after the last card has been completely answered.
Wrap Buckets: When checked, the buckets will wrap to the next row. When unchecked, the buckets will span on one row across the page.
Note: This affects desktops only.
Buckets Displayed Per Row: Allows you to enter the number of buckets to display on each row.
Note: Wrap Buckets must be checked.
Bucket Maximum Width: A number and CSS unit of measure used to limit the width of each bucket. Possible values include 10%, 150px, or 5em.
Card Maximum Width: A number and CSS unit of measure used to limit the width of each bucket. Possible values include 10%, 150px, or 5em.
Click Save and Preview to preview the settings. Once you are satisfied with the style options settings, click Save and Close.
4: Question Options
The options available for configuring question and response settings are displayed to the right of the staging area. Click any question or response option to set rules for it.
4.1: General Options
When altered, each of the following options affects all attributes within the Card Sort Single Select element.
Label: The label assigned to the element. Click to edit the default label for the Card Sort Single Select element.
Show If: Click to create new logic conditions or select an existing logic condition for the element. For more information, see Adding Logic to a Question or Response Option.
Languages: Click to select what languages the element will be shown in if the survey has multiple languages. The default is "all".
Mandatory: This is required and the box is checked by default.
Randomize: Check the boxes to randomize items by type. Items can be randomized by rows, columns, groups, or all.
Rating/Scale: Enables nets in the report. To learn how to set up your rating scale preferences in the report, see Editing Tables in Crosstabs.
More Options: Click to select less commonly used options. Once selected, you will be able to specify the setting for that option. For more information on each option, see More Options - Advanced Features.
4.2: Card Options
When altered, each of the following options only affects specific card attributes.
Label: The label assigned to the card. Click to edit the default label for the card.
Show If: Click to create new logic conditions or select an existing logic condition for the card. For more information, see Adding Logic to a Question or Response Option.
Languages: Click to select what languages the card will be shown in if the survey has multiple languages. The default is "all".
Do Not Randomize: This option is only available if the "Randomize" general option is selected. Check the box to force the card to remain stationary.
Optional: This option is only available if the "Mandatory" general option is selected. Check the box to make the card optional and non-mandatory.
Hidden: Click to hide the card from participants.
More Options: Click to select less commonly used options. Once selected, you will be able to specify the setting for that option. For more information on each option, see More Options - Advanced Features.
4.3: Bucket Options
When altered, each of the following options only affects specific bucket attributes.
Label: The label assigned to the bucket. Click to edit the default label for the bucket.
Data Value: The value assigned to the bucket in the data. You may edit the default value for the bucket here if the option is available.
Show If: Click to create new logic conditions or select an existing logic condition for the bucket. For more information, see Adding Logic to a Question or Response Option.
Languages: Click to select what languages the bucket will be shown in if the survey has multiple languages. The default is "all".
Do Not Randomize: This option is only available if the "Randomize" general option is selected. Check the box to force the bucket to remain stationary.
Hidden: Click to hide the bucket from participants.
More Options: Click to select less commonly used options. Once selected, you will be able to specify the setting for that option. For more information on each option, see More Options - Advanced Features.
