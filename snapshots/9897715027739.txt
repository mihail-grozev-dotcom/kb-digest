New Features

Bug Fixes
Reporting
Crosstabs
Fixed an issue where Crosstabs would not run for a project containing image files with incorrect file extensions.
Survey

Portal
Actions Menu

Fixed an issue where restricted shell users could not create surveys using the copy-survey command.
Added a validation to check for available disk space when using copy-survey to duplicate surveys.
Panel (legacy)
Fixed an error displaying for terminate elements due to a recent compat change.
