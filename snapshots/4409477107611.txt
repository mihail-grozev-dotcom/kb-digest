Title: Operating System Packages
Requires Decipher Cloud
Every Decipher instance utilizes Ubuntu 18.04 as its operating system. A limited scope of packages is installed on each instance to ensure its security and reliability.

Package Installation
Forsta does not install individual packages for Decipher instances. Every package install is a global change to all instances. To request that a package be added to the list of installed packages, please contact your account manager with the name of the package and the reason why it should be installed. All packages will require a security audit and approval by the Forsta engineering team prior to being added.
