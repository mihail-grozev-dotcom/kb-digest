Title: Decipher (previously Decipher) M33 Technical Release Notes
Release Date: May 10, 2016
Mission Statement
New survey compat level is 133. Use compat=”133” for all new surveys”. This enables:
Single select (radio) questions using FIR can be unchecked
The virtual table vterm is automatically added to reporting when setup survey attribute includes the value term
A new survey tag style attribute, ss:logoAlt, allows you to add the survey logo alt text.
New Features
Survey Builder
#21864: Survey builders will see visual indications in the survey elements menu, on the question tree, on the survey element, in device settings and when launching a project if an element is incompatible the project settings. Currently indications are for mobile devices only.
Because of the new device feedback feature, DQs have a new attribute <device>(meta.xml) which affect the warnings and the compatibility table shown in the survey element menu.
Theme Editor
Theme Editor Permissions brings control to supervisors over what themes are available for their sub-users to use on surveys. The options are: Full, Use All, Use Company, Use System, and None.
Field Report
#21925: Added additional metrics to the campaign tab. You can now split campaigns by email domains (gmail, yahoo, hotmail, aol, apple, and other). There is also a row displaying spam % on sends.[03/09/16]
#4222: The terminates tab now include rows for "Non-qualified" for quotas and "Disqualified" for data edits when a reason is given. Unspecified terminates that do not fall into the categories above will continue to be listed as "Unspecified Terminates."
Dashboards
#21694: Added a new publish button in dashboards to easily share public dashboards with other users. Also added a new duplicate button to easily copy an existing dashboard in a project. Note: This will only show for surveys created after 3/22/2016.[03/23/16]
Reporting
#22071: Multi-threaded reporting. Certain parts of the crosstabs/dashboard engine run in parallel. This can greatly accelerate very large reports. The number of threads is controlled by config.py option reportingThreads defaulting to 6. Certain large servers may benefit from higher setting. [4/20/16]
Crosstabs
#21561: Rows that are not randomized in the survey are no longer randomized in tables and charts when sorting [3/31/16]
#21600: Compat 133+ surveys using setup="term" will generate a virtual question, vterm, showing how each user was terminated
#22063: Table Editor now allows the user to exclude rows from mean statistics [4/27/16]
Dashboards
#21968: Word clouds can now use the keyword cloud.palette to use custom colors [3/29/16]
#21746: Survey titles can now be piped using {{survey.title}}[3/29/16]
Usage Statistics
#21496: Usage statistics has a new column for Video Testimonial counts, VT Responses Separated. This contains the counts for responses per question in a comma separated list. *NOTE: For existing surveys this count will not match the VT Responses column. The VT Responses Separated count begins the day it is merged [3/29/16]
