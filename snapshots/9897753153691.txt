Title: 147.12 Release Notes
Release Date: August 3, 2021
Release Version: 147.12
New Features
Survey
Panel Management (previously Kinesis) Integration
Improved the integration logging process by adding events for launching and closing registration surveys.
Programming & Tools
Custom Code Elements (Logic Nodes)
Added a new version of the RelevantID logic node (version 4), which enables use of Imperium's new "CustomFactor" parameter within surveys.
This new version is automatically applied to all new logic nodes and can be applied to old logic nodes by setting uses="relevantid.4" within the node’s <logic> tag.
The "CustomFactor" parameter is optional. If set, it returns some additional fields for each participant record which indicate whether that participant was a duplicate of a previous record.
