Title: Available Survey Languages
Decipher supports a large variety of languages that can be added to surveys using either the Language Manager Overview or the decLang variable in the XML Editor.
Adding a language to a survey will automatically translate its "Continue" and "Back" buttons, as well as its default error messages into that language. Survey question text, instructions, response options, and any additional language resources must be updated manually using the Language Manager.
The table below lists all the languages available for use within Decipher surveys. It also identifies if the language is available for AI translation.
Note: If you would like to add a language that is not included on this list, please contact your Account Manager or the Decipher Support team for assistance.
Note: To use Decipher's AI translation services, reach out to your Forsta representative to enable the Translate button. See Language Manager Overview--4: DeepL AI Translations for details.
Variations of supported source languages are translated using the main source language. For example, “Spanish (Costa Rica)” is translated using the supported source language “Spanish”.
Variations of supported target languages are translated using the main target language. For example, “Traditional Chinese (Taiwan)” is translated using the supported target language “Chinese (traditional)”.
