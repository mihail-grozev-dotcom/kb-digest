Title: Compatible Languages for Decipher & Panel Management Surveys
It is possible for Panel Management customers to include multiple languages in a survey that uses both Panel Management and Decipher. If a selected language is available for both Panel Management and Decipher, it is sent from Panel Management via the survey URL, populated in the survey for each panelist, and then sent back to Panel Management as the panelists' default language.
Note: Some survey languages are not compatible for both Decipher and Panel Management. If an incompatible language is set in the survey, it will only be applied there and not shared with Panel Management. See Decipher-Only Languages below for a full list of Decipher-only languages.
1: How it Works
If your Panel Management panel allows multiple languages and you expect to display your Decipher survey in a language other than English, you will need to add the corresponding Decipher language code(s) to your project. This can be done using the Language Manager within Decipher.
Once each language code is added within the Language Manager, the survey link will automatically append a Decipher language (decLang) variable for each language based on its mapping to Panel Management languages. If a panelist's language is not supported within Decipher, the default survey language will be used instead.
The table below lists all of the languages available for mapping within a survey using Panel Management and Decipher.
Note: Some languages do not have a matching language within Decipher. For these, you will need to select the default language and translate all text within the Decipher survey.

2: Decipher-Only Languages
Languages that are available in Decipher but not in Panel Management will not change a panelist's language in Panel Management. Instead, they will be set as English (not the panel's default language) for the panelist.
The following Decipher languages do not have an equivalent in Panel Management:
Azerbaijani
Khmer
Swahili
Tagalog
